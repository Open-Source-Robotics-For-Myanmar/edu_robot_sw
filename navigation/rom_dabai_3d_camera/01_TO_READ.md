##### သူတို့နှစ်ခုက 3d point cloud ရတာတော့ အတူတူပဲမို့လား
```
ဟုတ်ပါတယ်။ Astra နဲ့ Dabai ကင်မရာနှစ်ခုလုံးက 3D point cloud ကို ထုတ်ပေးနိုင်တာချင်း တူပါတယ်။

ဒါပေမယ့် သူတို့မှာ အသုံးပြုထားတဲ့ နည်းပညာ၊ ဒီဇိုင်းနဲ့ ရည်ရွယ်ချက်က မတူတာကြောင့် ရလာမယ့် point cloud ရဲ့ အရည်အသွေး (quality) မှာတော့ ကွာခြားချက်တွေ ရှိပါတယ်။

Point Cloud အရည်အသွေး ကွာခြားချက်များ
၁။ တိကျမှု (Accuracy) နဲ့ ဆူညံမှု (Noise)
Astra: Astra series မှာ Structured Light နည်းပညာကို သုံးထားပါတယ်။ ဒါကြောင့် အလင်းအားနည်းတဲ့နေရာတွေနဲ့ ထောင့်ချိုးမကျတဲ့ မျက်နှာပြင်တွေမှာ point cloud တွေက နည်းနည်းလေး ပုံပျက်တာ၊ ဆူညံတာတွေ ဖြစ်နိုင်ပါတယ်။

Dabai: Dabai က Binocular Structured Light နည်းပညာကို အသုံးပြုပြီး ပိုမိုတိကျတဲ့ point cloud တွေကို ထုတ်ပေးနိုင်ပါတယ်။ ၎င်းရဲ့ ဒီဇိုင်းဟာ စွမ်းအင်သုံးစွဲမှု နည်းအောင် အထူးပြုလုပ်ထားတာမို့ တိကျတဲ့ တိုင်းတာမှု လိုအပ်တဲ့ စက်ရုပ်တွေအတွက် ပိုကောင်းပါတယ်။

၂။ အနီးအဝေး တိုင်းတာနိုင်မှု (Range)
Astra: Astra ဟာ ပိုပြီး ကျယ်ပြန့်တဲ့ အကွာအဝေးကို တိုင်းတာနိုင်ပါတယ်။ မော်ဒယ်ပေါ်မူတည်ပြီး 0.6 မီတာကနေ 8 မီတာအထိ တိုင်းတာနိုင်ပါတယ်။ ဒါကြောင့် ကျယ်ပြန့်တဲ့ ပတ်ဝန်းကျင်ကို scan လုပ်ဖို့ အဆင်ပြေပါတယ်။

Dabai: Dabai ကတော့ ပိုပြီး ကန့်သတ်ထားတဲ့ အကွာအဝေး (ဥပမာ 0.3 မီတာ ကနေ 3 မီတာ) အတွင်းမှာပဲ ပိုပြီး ထိရောက်ပါတယ်။ ဒါကြောင့် ပတ်ဝန်းကျင်အကွာအဝေးကို တိတိကျကျတိုင်းတာဖို့ လိုအပ်တဲ့ စက်ရုပ်တွေအတွက် ရည်ရွယ်ပါတယ်။

၃။ ရုပ်ထွက် (Resolution)
Astra နဲ့ Dabai မော်ဒယ်အမျိုးအစားပေါ်မူတည်ပြီး point cloud resolution ကလည်း ကွာပါတယ်။ ပိုမိုမြင့်မားတဲ့ resolution ရှိတဲ့ မော်ဒယ်တွေက ပိုပြီး အသေးစိတ်တဲ့ 3D ပုံရိပ်တွေကို ရရှိနိုင်ပါတယ်။

အချုပ်အားဖြင့်ပြောရရင်၊ Astra နဲ့ Dabai ကင်မရာနှစ်ခုလုံးဟာ point cloud ကို ထုတ်ပေးနိုင်တာချင်း တူပေမယ့်၊ Astra က ပိုကျယ်တဲ့ အကွာအဝေးနဲ့ အသုံးပြုမှုမျိုးစုံအတွက် အဆင်ပြေပြီး Dabai ကတော့ တိကျမှုနဲ့ စွမ်းအင်ချွေတာမှု ပိုလိုအပ်တဲ့ စက်ရုပ်ပရောဂျက်တွေအတွက် ပိုကောင်းပါတယ်။
```
